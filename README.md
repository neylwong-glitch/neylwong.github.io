# CDIS 静态网站模板

双击 `index.html` 即可在浏览器打开，不需要安装依赖。也可以将整个文件夹放到任意静态网站服务器。

- `index.html`：页面结构与文案。搜索“人物代号”可替换角色名称，搜索“虚构”可调整背景说明。
- `styles.css`：颜色、排版和手机端布局。顶部 `--red` 可修改主题红色。
- `script.js`：手机端菜单开关。
- `assets/`：页面使用的原始图片，替换图片时保持文件名，或修改 HTML/CSS 内的路径。

首页主视觉与第一张人物档案卡已使用 `IMG_4091(3).jpeg`，并标注为 CDIS 创建人。

页面参考了提供的第一张网页的“导航—主视觉—下方卡片”结构，其余布局和文案为独立模板。所附人物图中可能含有游戏素材，公开发布前请确认使用权限。机构和公司介绍为虚构展示文案。
